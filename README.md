# Personal Portfolio Website

A modern, responsive portfolio website showcasing my skills, projects, and contact information.
Portfolio Site : [Portfolio](#https://portfoliozenzo.netlify.app/).

## Project Overview

This portfolio website is built with HTML5 and CSS3, featuring:
- Responsive navigation
- Hero section with call-to-action
- About me section
- Skills showcase
- Project portfolio
- Contact information
- Mobile-friendly design

## Project Structure

```
WEBD-Project/
├── index.html
├── style.css
├── .gitignore
├── images/
│   ├── ssfM.jpg
│   ├── weather.png
│   └── portfolio.png
└── README.md
```

## Features

- **Navigation:** Sticky header with smooth scrolling to sections
- **Hero Section:** Introduction with call-to-action button
- **About:** Personal introduction and background
- **Skills:** Display of technical competencies
- **Projects:** Showcase of recent work with images and descriptions
- **Contact:** Professional contact information and social media links

## Setup Instructions

1. Clone the repository
```bash
git clone <repository-url>
```

2. Navigate to the project directory
```bash
cd WEBD-Project
```

3. Open `index.html` in your preferred browser to view the website

## Development

To modify the website:
1. Edit `index.html` for structure changes
2. Modify `style.css` for styling updates
3. Add images to the `images/` directory
4. Update project content in respective sections

## Technologies Used

- HTML5
- CSS3
- Responsive Design
- Flexbox/Grid layouts
